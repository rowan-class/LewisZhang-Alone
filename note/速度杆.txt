实现一个“车速拉杆 / Speed Lever”状态机。

核心变量：
- leverPosition: float，范围 0.0 ~ 1.0
  - 0.0 = 初始点
  - 1.0 = 到底
- fuel: 当前油量
- hasPower: bool，车是否有动力
- state:
  - Idle
  - Pushing
  - ActiveHold
  - SlowReturn
  - FastReturn

状态含义：
1. Idle
   - 拉杆在初始点
   - leverPosition = 0
   - hasPower = false

2. Pushing
   - 玩家正在推杆
   - 条件：玩家按住 G + D，且 fuel > 0
   - hasPower = false
   - leverPosition 从当前位置向 1.0 增加
   - 只有到达 1.0 才能触发动力

3. ActiveHold
   - 拉杆已经到底
   - hasPower = true
   - leverPosition 保持在 1.0 一段时间
   - hold 时间结束后进入 SlowReturn

4. SlowReturn
   - 拉杆从 1.0 慢速回到 0.0
   - hasPower = true
   - 到达 0.0 后进入 Idle，并 hasPower = false

5. FastReturn
   - 拉杆快速回到 0.0
   - hasPower = false
   - 到达 0.0 后进入 Idle

全局打断规则：
- 只要玩家按住 G + D 且 fuel > 0，并且当前不是 ActiveHold，就立刻进入 Pushing。
- 这意味着 SlowReturn 和 FastReturn 过程中，玩家都可以重新推杆。
- Pushing 应该从当前 leverPosition 继续向 1.0 推，而不是重置位置。

油量规则：
- 任何状态下，只要 fuel <= 0：
  - 如果 state 是 ActiveHold 或 SlowReturn 或 Pushing，则进入 FastReturn
  - hasPower = false
- fuel <= 0 时不能进入 Pushing。

推进失败规则：
- 在 Pushing 中，如果玩家松开 G 或 D，且 leverPosition < 1.0：
  - 进入 FastReturn
  - hasPower = false
- 如果玩家成功把 leverPosition 推到 1.0：
  - 进入 ActiveHold
  - hasPower = true
  - 重置 holdTimer

状态流程：
Idle
  -> 玩家按住 G + D 且有油
  -> Pushing

Pushing
  -> 推到 leverPosition = 1.0
  -> ActiveHold

Pushing
  -> 松开按键 / 没油 / 未推到底
  -> FastReturn

ActiveHold
  -> hold 时间结束
  -> SlowReturn

ActiveHold
  -> 没油
  -> FastReturn

SlowReturn
  -> leverPosition 回到 0.0
  -> Idle

SlowReturn
  -> 玩家按住 G + D 且有油
  -> Pushing

SlowReturn
  -> 没油
  -> FastReturn

FastReturn
  -> leverPosition 回到 0.0
  -> Idle

FastReturn
  -> 玩家按住 G + D 且有油
  -> Pushing

实现注意：
- leverPosition 必须是连续值，不要只用 bool。
- 输入打断优先级高于 SlowReturn / FastReturn。
- 但 ActiveHold 不建议被玩家输入打断，因为拉杆已经到底。
- Pushing 过程中 hasPower = false。
- ActiveHold 和 SlowReturn 过程中 hasPower = true。
- Idle 和 FastReturn 过程中 hasPower = false。
- 快速复位和慢速复位都只改变 leverPosition，不要瞬移。
- FastReturn 速度应大于 SlowReturn 速度。

推荐伪代码：

update(deltaTime):
    inputPush = isKeyDown(G) && isKeyDown(D)
    hasFuel = fuel > 0

    if !hasFuel:
        if state != Idle:
            state = FastReturn
        hasPower = false

    else if inputPush && state != ActiveHold:
        state = Pushing

    switch state:

        Idle:
            leverPosition = 0
            hasPower = false

        Pushing:
            hasPower = false
            leverPosition += pushSpeed * deltaTime
            leverPosition = clamp(leverPosition, 0, 1)

            if leverPosition >= 1:
                leverPosition = 1
                state = ActiveHold
                hasPower = true
                holdTimer = holdDuration

            else if !inputPush:
                state = FastReturn
                hasPower = false

        ActiveHold:
            hasPower = true
            leverPosition = 1
            holdTimer -= deltaTime

            if holdTimer <= 0:
                state = SlowReturn

        SlowReturn:
            hasPower = true
            leverPosition -= slowReturnSpeed * deltaTime
            leverPosition = clamp(leverPosition, 0, 1)

            if leverPosition <= 0:
                leverPosition = 0
                state = Idle
                hasPower = false

        FastReturn:
            hasPower = false
            leverPosition -= fastReturnSpeed * deltaTime
            leverPosition = clamp(leverPosition, 0, 1)

            if leverPosition <= 0:
                leverPosition = 0
                state = Idle
